## Hardware simulator updates

The hardware now operate using 4 different channels :
- one FPGA file located at "/dev/cmd" to read the controller commands
- one FPGA file at "/dev/c2h_angles" to write the rotation angles
- one FPGA file located at "/dev/h2c_gc" to read the global counter to use for the PRNG
- one FPGA file located at "/dev/c2h_click_results" to write the measurements

### Input Commands

The input commands on "/dev/cmd" are :
- Start=0x27
- Stop=0x26

No response is expected.

### Workflow

#### Alice's simulator
- Simulator receives Start command through the cmd_file (FPGA file) -> No response. Do nothing.
- Simulator waits for global counter of click (gc) on /dev/xdma0_h2c_0. Once GC received, set the prng seed to gc
and start generation of Random values and write them onto /dev/xdma0_c2h_3 until Stop message is received on the cmd_socket.

### Bob's simulator
- Simulator receives Start command through /dev/cmd (fpga file) -> No response. Do nothing.
- Simulator writes global counter of click (gc) and measurement result of click (r) to the fpga file /dev/xdma0_click_results.
- Simulator waits for global counter of click (gc) on /dev/xdma0_h2c_0. Once GC received, set the prng seed to gc
and start generation of Random values and write them onto /dev/xdma0_c2h_3 until Stop message is received on /dev/xdma0_user.

The bytes generated by the PRNGs of each simulator are synchronised because the gc value they received are always synchronized.
Using this gc as seed assures that the generated bytes are the same. 

#### Extract angles and click results 
Use the following formula to extract the value of the angles and the click_results from the random values (namely data):
let (angles_data, click_results_data): (Vec<u8>, Vec<u8>) = data
                        .chunks_exact(2)
                        .map(|chunk| {
                            let byte1 = chunk[0];
                            let byte2 = chunk[1];
                            let angle_byte = ((byte1 & 0b110) >> 1) | ((byte2 & 0b110) << 3);
                            let result_byte = (byte1 & 0b001) | ((byte2 & 0b001) << 4);
                            (angle_byte, result_byte)
                        })
                        .unzip();
